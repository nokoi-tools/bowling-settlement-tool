プライバシーポリシー

最終更新日: 2026年8月2日

1. サービス名

本ポリシーは、Nokoi Tools が提供する「ボウリング精算・差額計算ツール」（以下「本サービス」）に適用されます。

2. データの保存について

本サービスは、入力されたプレイヤー名・スコア・チーム設定・精算設定などを、お使いのブラウザ内の LocalStorage に保存します。データは端末内に保持され、通常はサーバーへ送信されません。

3. サーバーへの送信

現時点では、入力データを運営者のサーバーへ送信する機能はありません。ただし、ウェブホスティングや CDN 等のインフラ提供者へ、アクセスログ程度の情報が記録される場合があります。

4. 将来の変更

今後、利用状況の把握のためアクセス解析（Google Analytics 等）や広告配信を導入する可能性があります。その場合は本ページを更新し、必要に応じて同意取得の方法を明示します。

5. 第三者サービス

共有機能では、端末の Web Share API やクリップボード機能を利用します。外部サービス（LINE 等）への送信は、利用者自身の操作により行われます。各サービスのプライバシーポリシーが適用されます。

6. 免責事項

LocalStorage のデータ消失（ブラウザ設定、端末変更、キャッシュ削除等）について、運営者は復旧の責任を負いません。重要なデータは別途ご自身で保管してください。

7. お問い合わせ

本ポリシーに関するお問い合わせ: contact@nokoi.tools（仮）
